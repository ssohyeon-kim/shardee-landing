# 콘텐츠 이관·대조 기록

수집 원본과 시각, SHA-256은 `content-sources.json`에 기록했다. 원본 HTML의 서버 렌더링 데이터 중 해당 문서의 공개 `snapshot.blockTree` 및 `blockMap`만 추출해 `faq-source.json`, `privacy-source.json`, `terms-source.json`으로 보관했다. 실제 페이지에 포함된 블록 순서·중첩 구조는 `blockTree`를 기준으로 했다. 외부 사이트는 일반 빌드와 방문 시 다시 조회하지 않는다.

개인정보 처리방침은 v1.3.2, 최종 업데이트·현재 시행일은 2026-10-14, 이전 시행일은 2026-10-01이다. 이용약관 최종 업데이트는 2026-10-01이다.

- FAQ는 질문·답변을 가격·프리미엄, 촬영, 저장, 편집, 구매·환불, 권한·문제 해결로 묶었다. 질문별 기본 HTML details/summary를 사용하여 자바스크립트 없이 열람할 수 있다.
- 한국어/영어 앱 소개와 공지를 모두 보존했다. 영어 소개와 공지만 별도 펼침으로 배치했고 새로운 영문 경로는 만들지 않았다.
- 원문에서 연결한 영어 FAQ·정책·약관은 모두 HTTP 200과 문서 제목을 확인했다. 원래 목적지 그대로 유지했다.
- FAQ 환불 안내에서 텍스트로만 제공되던 `reportaproblem.apple.com` 및 `play.google.com`은 각각 동일한 호스트의 HTTPS 링크로 만들었다. 표시 문구는 동일하다.
- FAQ 답변은 수집 시 텍스트를 escape하고 정해진 p/ul/li/strong/em/h3/a 태그로 변환한 로컬 데이터다. 원격 HTML을 실행하거나 사용자 입력 HTML을 주입하지 않는다.
- 공통 footer의 사업자 정보는 공통 설정에서 관리한다. 법률 문서에 속한 운영자·책임자·주소·문의 문구는 원문 이관을 위해 본문에도 그대로 보존했다.

## 공개 전 운영 검토 사항

아래 내용은 개발 단계에서 임의 수정하지 않았다.

1. 개인정보 처리방침 6조에는 도움말·정책 문서를 Slashpage에 호스팅할 수 있다는 안내와 Slashpage의 개인정보처리방침 링크가 있다. 새 정적 사이트 운영과 기존 Slashpage 유지 여부를 운영자가 검토해야 한다.
2. FAQ 끊김 현상 답변의 해상도 `1080k`는 원문 그대로다. 실제 앱 동작을 확인하지 않고 `1080p`로 바꾸지 않았다.
3. FAQ의 `랜더링`, `갯수`, 갤러리 질문 끝에 중복된 설정 안내 등 표현도 원문대로 보존했다.
4. 개인정보 8조의 앱 삭제 안내와 5조의 이미 전송된 분석·진단·문의 정보 삭제 안내를 모두 보존했다. 해석이나 법률 판단으로 문구를 통합하지 않았다.
5. 기존 Slashpage·앱·스토어에 연결된 정책 URL의 교체는 최종 도메인과 공개 배포 이후 운영 작업이다. 이번 구현에서는 앱 코드와 기존 Slashpage를 수정하지 않았다.

## 재현 가능한 대조

빌드한 후 `node docs/reference/verify-content.mjs` 또는 `npm test`를 실행한다. 검증기는 원본 `blockTree`에 실제 포함된 각 블록의 전체 텍스트를 해당 페이지의 article 또는 해당 FAQ의 details 내부와 대조하고, 모든 원본 clickAction 링크와 영문 페이지 링크를 검증한다. 공백·HTML entity 차이만 정규화한다. 단순 조항 개수뿐 아니라 소개·공지·질문·답변·하위 목록 전체를 비교한다.

2026-10-30 최초 빌드 산출물 대조 결과: 개인정보 13조항/151개 본문 블록, 이용약관 16조항/136개 본문 블록, FAQ 18문항 및 소개·공지 포함 65개 본문 블록이 모두 일치했다. 원문 clickAction 링크와 영문 안내 링크도 통과했다.

## 다국어 확장 후 변경

2026-10-30 사용자 요청에 따라 헤더 언어 선택기로 전환을 통일했다. `Terms of Use (En)`, `Privacy Policy (En)`, `FAQ in English` 같은 기존 외부 영문 바로가기만 UI에서 제거했다. 원본 snapshot은 보존하며 대조 검증에서는 알려진 두 영어 문서 이동용 note 블록만 제외한다. 법률 조항·본문·제3자 개인정보 정책 링크에는 이 제외를 적용하지 않는다. 번역 언어는 영어·일본어·번체·간체이며 한국어 원문과 문단·목록·번호·의무 내용을 보존한다.
