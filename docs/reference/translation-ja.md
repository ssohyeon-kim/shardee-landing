# 日本語翻訳の記録

作成日：2026-10-30。ロケール：`ja`。韓国語のローカル原文を翻訳し、新たな法的義務、権利、免責条項は追加していない。翻訳であることは共通文書UIの「韓国語原文からの翻訳です。」という表示で案内する。法的本文には翻訳に関する新しい条項を挿入していない。

## 翻訳対象

- `src/i18n/locales/ja.json`：韓国語UIと同じ75個の末端キー。ナビゲーション、SEO情報、ホームの全文、動画操作、画像の代替テキスト、ストアリンクのアクセシブル名、FAQのUI、文書のUI、フッター、404の文言を含む。
- `src/content/translations/ja/faq.json`：導入2ブロック、注意事項2件、質問18件と全回答、全サブリスト、6カテゴリー。
- `src/content/translations/ja/privacy.md`：13条すべてと第2条A〜Fの全小項目。更新日、版番号、施行日、問い合わせ先と外部リンクを保持。
- `src/content/translations/ja/terms.md`：16条すべて、歩数機能の小項目、返金の引用文を含む全段落・箇条書き。
- `privacy-toc.json`、`terms-toc.json`：翻訳済みの本文見出しに完全一致する目次。

原文：`src/i18n/locales/ko.json`、`src/content/translations/ko/faq.json`、`src/content/legal/privacy.md`、`src/content/legal/terms.md`。元の公開原文・収集時刻は文書のfrontmatterと`docs/reference/content-sources.json`を参照。

## 保持した情報

FAQの18個の`id`と`sourceBlockId`、回答のHTMLタグの順序・ネスト・属性、ストアの返金リンクを保持した。法律文書の`section-1`以降のID、全HTML属性、MarkdownリンクのURL、メールアドレス、日付、バージョンおよび数値を保持した。

Shardee、DIARO、各製品・サービスの名称、`김소현`などの固有名詞を保持した。韓国の住所と機関名は、日本語表記で同じ所在地・機関を示している。原文のFAQにある`1080k`や、プライバシーポリシーにあるSlashpageのホスティングについての説明は、推測で訂正・削除していない。AndroidとiOSの説明にある差異も原文に従っている。
